**Zupermarket Zimulator 0.9.4: getting ready for the Microsoft Store.**

## Downloads
- **Android** (phones, tablets, AYN Thor and other handhelds): `ZupermarketZimulator-android.apk`
- **Windows** (64-bit): `ZupermarketZimulator-windows.exe` (a single file, no installer)

It installs over earlier versions and keeps your saves. On Windows, 0.9.3 updates itself to this version.

## New in 0.9.4
- **The game can now be packaged for the Microsoft Store.** Store games never get the "Windows protected your PC" warning, and the Store keeps them up to date.
- The Store version leaves updating to the Store: it never updates itself or goes online. Nothing changes in the downloaded .exe or on Android.

## Also in 0.9.3
The game updates itself on Windows: it downloads new versions in the background and they start the next time you open it, with no security warning. Android's main menu tells you when a new version is out.

## Installing
- **Android / AYN Thor:** open the APK link in the device's browser and tap the download. Android will ask you to allow installs from that browser (Settings → Install unknown apps). Allow it, go back and tap **Install**.
- **Windows:** if you're on 0.9.3, the game updates itself. Otherwise download it once; if you see "Windows protected your PC", click **More info → Run anyway** (the game isn't code-signed). After that it updates itself.
