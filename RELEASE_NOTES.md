**Zupermarket Zimulator 0.20.1: automatic updates on Android. From this version on, the game downloads new versions by itself and opens Android's installer for you: just tap Update.**

## Downloads
- **Android** (phones, tablets, AYN Thor and other handhelds): `ZupermarketZimulator-android.apk`
- **Windows** (64-bit): `ZupermarketZimulator-windows.exe` (a single file, no installer)

It installs over earlier versions and keeps your saves. On Windows, 0.9.3 and later update themselves to this version.

## New in 0.20.1
- **Automatic updates on Android.** When a new version comes out:
  - The game downloads it in the background and checks it's all there.
  - On the main menu it opens Android's installer with it. Tap **Update** and your saves stay.
  - The first time, Android asks you to allow installs from Zupermarket Zimulator: flip the switch, go back, and tap **Update**.
  - Cancelled it? The main menu's **Install update** button opens it again. In the middle of a game it waits until you go back to the main menu.
- **Install this version by hand once** (the old versions can't do it themselves). After that, the game keeps itself up to date.
- **Options > Automatic updates** still turns it off.

## Installing
- **Android / AYN Thor:** open the APK link in the device's browser and tap the download. Android will ask you to allow installs from that browser (Settings → Install unknown apps). Allow it, go back and tap **Install**.
- **Windows:** on 0.9.3 or later, the game updates itself. Otherwise download it once. If you see "Windows protected your PC", click **More info → Run anyway** (the game isn't code-signed).
